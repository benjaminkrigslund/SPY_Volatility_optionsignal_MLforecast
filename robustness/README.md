# Robustness Folder

`scripts/` contains robustness and diagnostic scripts, including:

- alternative rolling-window checks,
- QLIKE-tuned model-universe runs,
- common-sample MCS checks,
- refit-frequency variants,
- extended model/combination diagnostics.

`output/tables/` and `output/figures/` contain robustness outputs. The core 60- and 180-month rolling-window tables are generated by `R/05_run_rolling_forecasts.R`; extra robustness diagnostics are run through `R/10_robustness_checks.R`.
