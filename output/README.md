# Output Folder

This folder contains final paper outputs.

- `tables/`: CSV, Markdown, LaTeX, Excel, and Word tables used in the paper or appendix.
- `figures/`: final PNG figures used in the paper or appendix.
- `diagnostics/`: reserved for final diagnostics that are useful for review but not central paper tables.

Main-table outputs start with `main_forecast_`. VRP/economic-value outputs start with `economic_value_vrp_`. Robustness-only outputs are stored under `robustness/output/`.
