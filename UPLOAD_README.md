# Upload Folder

This folder is the curated project submission package. It contains the working code, current paper files, required data, final output tables/figures, and robustness material.

## Included

- `R/`: active project workflow and helper functions.
- `data/raw/`: required raw input files listed in the submission checklist.
- `data/processed/`: final master dataset, feature dictionary, and main forecast panel.
- `docs/paper_drafts/`: current project paper files and appendix document.
- `docs/official/`: official course/project guidance kept with the submission material.
- `output/`: final paper tables and figures.
- `robustness/`: robustness scripts and final robustness outputs.

## Intentionally Excluded

- `extra/`: exploratory scripts, quick tests, old drafts, and legacy outputs.
- `archive_delete_candidates/`: duplicate, temporary, IDE, and obsolete files.
- `.DS_Store`, `.Rhistory`, Word lock files, and other local metadata.
- `data/processed/model_artifacts/`: bulky intermediate artifacts that can be regenerated by the workflow.
- Very large non-final output tables that are not needed for the paper package.

## Reproduce

From this folder, run:

```r
source("R/00_run_all.R")
```

Before final submission, confirm that the raw data in `data/raw/` are allowed to be redistributed.
