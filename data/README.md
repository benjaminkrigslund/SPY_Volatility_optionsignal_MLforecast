# Data Folder

`data/raw/` contains the raw inputs used by the project. Before final ZIP submission, confirm that the option, factor, and market data licenses allow redistribution.

`data/processed/` contains reproducible intermediate and analysis-ready datasets:

- `master_dataset.csv`: final monthly master dataset with target, HAR, option, and macro predictors.
- `master_feature_dictionary.csv`: feature-group and source-name map.
- `forecast_panels/main_forecast_forecast_panel.csv`: main 120-month rolling forecast panel.

Bulky intermediate `model_artifacts/` files are excluded from this curated
upload package because they can be regenerated by the workflow.

If raw data cannot be shared, leave `data/raw/` out of the final ZIP and include instructions for obtaining the required files.
